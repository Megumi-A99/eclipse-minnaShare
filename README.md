# 名称
minnaShare(ミンナシェア)
# 制作の目的
常に新しい情報が行き交う販売接客の現場において、情報の均等化を促進するためにWebアプリケーションを制作しました。<br>
前職で携帯電話販売員として様々な手続きを行う中、一部のスタッフしか担当したことがない業務が存在し、業務の属人化が発生していました。
また情報の入れ替わりが激しいことで、古い情報のまま手続きや案内をしてしまうケースや、スタッフと口頭による内容確認に留めてしまい
全スタッフに情報が行き届いていないケースも存在していました。<br>
以上のような課題を解決すべく、新しい情報やスタッフが対応した複雑な手続きやイレギュラー対応を積極的に共有できる環境を構築したいと考え、
今回の制作に至りました。
# 開発環境
Eclipse, Apache Tomcat, H2DataBase, Gemini 
# 利用した言語
Java, HTML, CSS
# 設計書
# 今後展開したい拡張機能
・新着投稿をホーム画面の先頭に掲出させる。
・投稿内容の閲覧ページに、絵文字ボタンによるリアクション機能を搭載する。<br>
リアクション反応数はスタッフごとに集計され、月ごとに有益な情報提供をしたスタッフとしてランキング化する。
・外部サイトと連携し、スタッフの知識補填に役立てる情報提供ができるページを制作する。
