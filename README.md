# プロジェクト名
minnaShare(ミンナシェア)

# 制作の背景と目的
常に多くの情報が行き交う販売接客の経験から、情報共有を促進するためのWebアプリケーションを開発しました。<br>
前職で携帯電話販売員として様々な手続きを行う中、いくつかの課題がありました。<br>
1.一部のスタッフしか担当したことがない業務が存在し、業務の属人化が発生。<br>
2.情報の入れ替わりが激しいことで、古い情報のまま手続きや案内をしてしまう。<br>
3.スタッフと口頭による内容確認に留めてしまい全スタッフに情報が行き届いていない。<br>
以上のような課題を解決すべく、最新の正しい情報をすべてのスタッフが把握できる環境を構築したいと考え、本Webアプリケーションの開発に至りました。<br>
上記の課題に対して、２つの方法を取り入れました。<br>
【1.知識共有と閲覧機能】<br>
<img width="524" height="395" alt="inf" src="https://github.com/user-attachments/assets/d5940775-8d6d-4295-8d5e-1fbe47705976" />
<br>
複雑な手続きやイレギュラー対応の記録を掲示板形式で投稿できる機能を実装しました。これにより個人の頭の中にあるノウハウを他スタッフにも共有することができ、業務の属人化の解消に繋がると考えました。<br>

【2.優先順位の明確化】<br>
<img width="457" height="470" alt="post" src="https://github.com/user-attachments/assets/dc8d9708-7253-4e90-b301-c1058b082915" /><br>
情報の入れ替わりが激しい現場でも迷わず確認できるよう、投稿時に「重要度」を設定できる機能を盛り込みました。
重要度を視覚的に定義することで、忙しいスタッフでも優先して閲覧すべき情報が瞬時に判断できるように工夫しました。<br>
>【重要度を分ける判断基準】<br>
高：必ず把握するべき情報<br>
中：把握することで業務に役立つ情報<br>
低：緊急性はあまりないが業務の合間に確認してほしい情報<br>

# 今後展開したい拡張機能
・新着投稿をホーム画面の先頭に掲出させる。<br>
・投稿内容の閲覧ページに、絵文字ボタンによるリアクション機能を搭載する。<br>
・リアクション反応数はスタッフごとに集計され、月ごとに有益な情報提供をしたスタッフとしてランキング化する。<br>
・外部サイトと連携し、スタッフの知識補填に役立てる情報提供ができるページを制作する。
